# 开发与测试

三层验证，按"能不能自动化"分开，避免把账号依赖塞进公共 CI。

## 1. 离线用例（任意 Python 3.10+，不需要 KiCad/EDA）

```powershell
python tests\offline\test_gate_unconnected.py     # F01：未连接不得放行
python tests\offline\test_compare_states.py       # F10：对照五态
python tests\offline\test_template_min.py         # 模板最小化断言
python tests\offline\test_release_manifest.py     # 发布清单/哈希一致
python tests\offline\test_config_priority.py      # 配置优先级与 BOM 容忍
```

每个文件都能直接运行，也提供 `test_*()` 供 pytest 收集（装了 pytest 时
`python -m pytest tests/offline -q`）。

覆盖范围是**纯逻辑**：Gate 判定、对照状态机、模板白名单、发布清单、配置解析。
不含任何几何转换。

## 2. KiCad 环境用例（需要 `pcbnew`）

用 KiCad 自带的解释器（它带 pcbnew）：

```powershell
& "D:\Software\Electrical\KiCAD10\bin\python.exe" tests\fixtures\make_fixtures.py --out out\fixtures
& "D:\Software\Electrical\KiCAD10\bin\python.exe" tests\kicad\test_conversion_fixtures.py
```

用例覆盖：

| 用例 | 缺陷 | 断言 |
|---|---|---|
| 无铺铜板 | F02 | 转换 exit=0，输出含 `POUR=0` 提示 |
| 同封装两次 | F03 | 板级钢网 `FILL` = 2，中心 X = 196.9 / 590.6 mil |
| 印膏扩展 | F04 | `topPasteExpansion` = 3.937 / 11.811 mil，封装变体 = 2 |
| 改名内层 | F08 | 走线 `layerId = 15`，不出现 13 |

测试板由 `tests/fixtures/make_fixtures.py` 用 pcbnew 现造，**不入库二进制**，
也不引用第三方工程。

## 3. 需要账号的 EDA 实测（手工，不进自动化）

完整重建会写账号工作区，必须人工触发，**只用新建的命名测试工程**：

```powershell
python -m rebuild_in_jlc.pipeline --board "C:\boards\case.kicad_pcb" `
       --name Case --out out\case --stop-after rules
```

跑完整流程（含导入、重铺、DRC、导出、对照）时建议用 GUI：
它会先确认覆铜，再继续后续步骤，并在控制台打印结论。

## 4. 数据与口径

- 转换器 `tools/kicad2eprj3.py`：`--allow-unknown-layer` 才有"层映射失败仍继续"，
  默认阻断；`--with-poured` 才会写 `POURED` 填充。
- 对照工具 `tools/compare_gerber_layers.py`：务必传 `--source-copper N`，
  否则内层"是否不适用"只能按 EDA 包推断（会在报告里声明）。
- 发布包构建：`python scripts\build_release.py --version 0.4.0`，
  只打 git 跟踪文件，产出 `BUILD_INFO.json`（commit / dirty / 逐文件 SHA256）。

## 6. 体检工具（手工，建议每次改动后跑）

```powershell
# 扫出会被 EDA 丢弃的长折线（板框层除外）
python tools\check_polyline_limits.py out\some_run

# 逐盘核对焊盘网络与 KiCad 是否一致（需要 pcbnew）
& "...\KiCAD10\bin\python.exe" tools\verify_pad_nets.py board.kicad_pcb out\some_run
```

判定口径：`check_polyline_limits` 报"无超限折线"即通过（退出 0）；`verify_pad_nets` 退出 0 表示网络一致，
3 表示只有"同号多焊盘分属不同网络"（如 USB 屏蔽壳），2 表示真的丢网络/不一致。
