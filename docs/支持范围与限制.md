# 支持范围与限制

本页说明**哪些对象能迁移、哪些不能**，以及哪些环节必须人工完成。与 README 的"当前验证情况"配合看。

## 1. 对象支持矩阵

| 源对象（KiCad） | 现状 | 说明 |
|---|---|---|
| 器件实例（位置、角度、面别） | 支持 | 底面器件按"编辑器会镜像"的实测行为处理（局部坐标镜像 Y、焊盘层写 1） |
| 焊盘：椭圆 / 长圆 / 矩形 / 圆角矩形 | 支持 | 圆角矩形用 `RECT` + **百分比** `radius`（编辑器存 25 表示 25%） |
| 焊盘：多边形、倒角、自定义形状 | **不支持** | 会退化为矩形/长圆，制造级使用前须核对 |
| 焊盘级铺铜连接方式（`zone_connect`） | 支持 | THT→热焊、SMD→直连、覆盖值优先；NPTH→不连 |
| 通孔与槽孔（含斜槽、偏孔） | 支持 | 槽孔：`width=长边`，纵槽靠焊盘整体 +90° 表达 |
| 盲孔 / 埋孔 | **不支持** | 过孔一律按通孔写出 |
| 走线（直线/圆弧） | 支持 | 圆弧按中点恢复真实扫角后离散（板框弧实测偏差 0.001 mm） |
| 过孔 | 支持 | 尺寸取自源；连接方式恒为直连（与源一致） |
| 铺铜边界 + 网络 | 支持 | **只写边界**，填充由 EDA 自己算 |
| 铺铜填充结果 | **不写，但会自动触发重算** | 外带填充会与编辑器重算结果叠加；改为导入后调用 `rebuildCopperRegion()` 让编辑器自己算 |
| 禁布区（板级 / 封装内） | 支持 | 用 `REGION(PROHIBIT)`；封装内 zone 轮廓是**绝对坐标**，需换回局部 |
| 丝印线条 / 圆 / 弧 / 多边形 | 支持 | 统一离散为折线 |
| 丝印文字、位号、值 | 位置尺寸一致；KiCad 笔画字体映射为 **Arial** | 用 Arial 是为了让"反相"（白底挖空字）能渲染；源板已有字体名的保持原样。字形与原设计仍有差异 |
| 位号/值与器件的父子联动 | **不支持** | 可见文字是独立图元，改位号/移动器件后要手工同步 |
| 仅钢网焊盘（独立印膏窗口） | 支持 | 用 `FILL(SOLID)` 生成实心开窗 |
| **封装内铜层图形**（天线、铜标志等）| 支持（网络按覆盖焊盘推断）| 闭合多边形→`FILL(SOLID)`；开放折线→带线宽 `POLY`。网络优先取"多边形覆盖到的非电源/地焊盘"，否则留空 |
| 板级铜层图形 | 支持 | 同上，落在 PCB 文档里 |
| 阻焊/钢网扩展 | 按焊盘实际值写入 | 编辑器与 KiCad 的表示不同，需按开窗几何复核 |
| 原理图 / BOM / CPL / 3D | **不迁移** | 超出本项目范围 |
| 自定义内层名（如 In1.Cu → PWR） | **风险项** | 层号按显示名映射，可能落到文档层；含重命名内层的板必须核对层归属 |
| 设计规则（网络类、差分、局部规则） | 部分 | 只应用**间距类预设**；不等于迁移了源板全部规则 |

## 2. 必须人工完成的环节

| 环节 | 为什么必须人工 |
|---|---|
| 「设计 → 重建覆铜」 | **默认已自动**（`pour.rebuildCopperRegion()`，等价 Shift+B）；仅在编辑器拒绝或没有 POUR 时需人工兜底 |
| 确认目标工程/账号 | 导入写的是**当前登录账号**的工作区，程序不会替你判断账号是否正确 |
| 复核 DRC 明细 | "步骤完成"与"检查通过"是两件事，程序目前也没有制造放行判定 |
| 复核最终制造资料 | 开窗几何、孔位集合、丝印可读性等仍需独立的 CAM 侧复核 |

## 2.1 自动重铺：能力探测与降级

自动重铺依赖编辑器内部方法 `pour.rebuildCopperRegion()`（**未出现在官方 API 文档**）。
因此实现按"先探测、再调用、失败给下一步"设计：

| 场景 | 判定方式 | 退出码 | 处置 |
|---|---|---|---|
| 正常 | `POURED` 数量达到预期 | 0 | 继续 DRC |
| 接口不存在 | 探测 `rebuildCopperRegion` 非函数，**不做任何写操作** | 3 | 手工 Shift+B，在同一次 GUI 流程里确认 |
| 没有铺铜 | `POUR` 数量为 0 | 5 | 检查源板/导入是否完整 |
| 没有 PCB 文档 | 铺铜 API 抛错且打不开 PCB 页 | 8 | 先打开 PCB 页或跑 `eda_open_project.py` |
| 没有会话 | `session list` 无 `origin=user, alive` | 4 | 登录 EDA 并打开工程 |
| 编辑器拒绝 / 超时 | 调用成功但 `POURED` 仍为 0 | 6 | 手工 Shift+B 复核，看覆铜相关 DRC |

工具会自动**打开第一块 PCB 文档**后重试一次（实测：文档未打开时 `pcb_PrimitivePour.getAll()`
会直接抛 `Cannot read properties of null`，不是返回空数组——这一点必须显式处理）。

已验证：嘉立创EDA 专业版 **4.1.100** 支持该方法；升级后若方法被改名，会落到"接口不存在"分支，
不会静默失败。

## 3. 规则档位

| 档位 | 间距 | 用途 |
|---|---|---|
| `kicad` | 0.127 mm | 与 KiCad 默认网络类一致 |
| `kicad-min` | 0.12 mm | 默认；略低于 KiCad 值 |
| `kicad-loose` | 0.11 mm | 板内有更紧结构时使用 |

换档位会**改变检查条件**，必须记录所用档位；档位宽松后出现的"DRC 通过"不能作为保真证据。

## 4. 已知差异（记录在案，非缺陷宣告）

- 丝印字形：同位置同尺寸，笔画数不同（示例：EDA 902 段 vs KiCad 918 段）；
- 铜层图元统计：EDA 226 闪绘 vs KiCad 224（差值来自散热盘分块）；
- 阻焊层：EDA 用光圈闪绘、KiCad 用多边形表示，只能按"开窗数量 + 位置"比对；
- 钻孔图（GDD）：EDA 额外画出完整钻表，文件更大，不影响下单数据。

## 5. 第 ⑨ 步"统计对照"的口径

`tools/compare_gerber_layers.py` 输出的是**图元统计摘要**：

- 比较：闪绘数、区域数、线段数、字节数、简化包围盒、刀具/孔数/槽数；
- **不比较**：完整孔位集合、铜几何轮廓、网络连通性；
- 参考层缺失时该层**不参与比较**，并会在末尾列出"缺失的参考层"、退出码 3。

因此它的 OK 只说明"统计层面没有明显异常"，不能解释为逐层等价。

## 6. 当前版本的行为要点（0.4.0）

> 历史改动与修复记录请看 [CHANGELOG](../CHANGELOG.md)；本节只写"现在会怎样"。

| 场景 | 现在的行为 |
|---|---|
| 源板无铺铜区 | 转换正常完成；自动重铺返回 `not_needed`（正常）。仍建议对照源板确认不是转换漏区 |
| 同一封装放置 N 次、含仅钢网焊盘 | 生成 N 个板级钢网窗口；圆/椭圆等按**焊盘真实形状**生成（1 mm 圆窗 ≈0.784 mm²）|
| 焊盘设了印膏/阻焊扩展 | 写成具体 mil 值；X/Y 不同时取较大者并告警（EDA 只支持单值）|
| 重命名内层（如 `In1.Cu`→`PWR`） | 按 **KiCad 层 ID + 叠层顺序**映射；无法映射的层**默认阻断**，`--allow-unknown-layer` 才继续 |
| 同号多焊盘（USB 屏蔽壳、测试点） | `PAD_NET` 用 padId 定位到具体那一枚焊盘，网络不会被互相覆盖；逐枚核对工具见 `tools/verify_pad_nets.py` |
| 丝印折线很长（logo 等） | 0.4.0 起**不截断、不预抽点**；仅超阈值（默认 2000 点）才做误差受控简化，达不到就降级并写 `degraded_polylines.json` |
| 对照参考缺内层/缺钻孔 | 记 `missing_evidence`（退出码 3），不当"两层板正常" |
| EDA 与 KiCad 包围盒整体偏移 > 0.5 mm | 记 `differs`（退出码 4）|
| Gerber 插件遇未连接项 | `publishable=false`，只产出 `*_DIAGNOSTIC.zip` |

### 6.1 EDA 侧实测限制（专业版 4.1.100）

| 限制 | 表现 | 本工具的处理 |
|---|---|---|
| 板级 POLY 不进 3D 预览 | Gerber 正确，3D 里看不到 | 圆/弧等丝印写进封装文档；板级丝印图形仍属已知限制 |
| ARC 图元不支持丝印层 | `pcb_PrimitiveArc.create(layer=3)` 报参数错误，铜层正常 | 不用 ARC 表达丝印圆环 |
| 封装内折线"点数上限" | 实测 80…2000 点全部正常渲染，**未发现上限** | 默认不简化 |

> 以上只是 4.1.100 上的受控观察，不要外推为"所有版本都不支持"。
